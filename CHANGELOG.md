## 1.2.0

What's new:
- Archive and restore titles, copies and members
- Fill in a book's details from its ISBN
- Check for updates from the account menu
- The Windows installer updates itself in one click, after a backup
- Support section in About

## 1.1.2

What's new:
- Loans page listing every open loan
- Tidier library and loan settings
- Support links in About
- New web loading screen and icons

## 1.1.1

What's new:
- The web version now lives at app.khulladigitallibrary.com
- Android builds signed for Google Play

What's new:
- Return a loan by scanning its barcode
- Barcodes for members and staff
- More member details: gender, blood group, address, occupation, institution, ID and emergency contact
- Find staff by barcode
- More reliable saving on the web

What's new:

- Add copies straight from a title's page
- New members start with the public member type

- First stable release
- Built-in guide and a printable user manual
- Faster search for titles and members
- Add and crop your library's logo

## 0.1.0
